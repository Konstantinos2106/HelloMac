# 🛠️ Οδηγός Build & Ανάπτυξης

Αν θέλετε να κάνετε compile (build) το **HelloMac** από τον πηγαίο κώδικα, η διαδικασία έχει αυτοματοποιηθεί πλήρως μέσω ενός bash script (`build_hellomac.sh`).

## 📋 Απαιτήσεις Συστήματος

Για να εκτελεστεί επιτυχώς το script μεταγλώττισης, το σύστημά σας πρέπει να πληροί τις εξής προϋποθέσεις:

- **Λειτουργικό Σύστημα:** Απαιτείται macOS 11.0 (Big Sur) ή νεότερη έκδοση, καθώς ορίζεται ως το ελάχιστο σύστημα κατά τη μεταγλώττιση. Η διαδικασία υποστηρίζει αυτόματα και τις δύο αρχιτεκτονικές: Apple Silicon (`arm64`) και Intel (`x86_64`).
- **Εργαλεία Ανάπτυξης (Command Line Tools):** Απαιτείται ο μεταγλωττιστής της Swift (`swiftc`) και τα εργαλεία συστήματος της Apple (`xcrun` για το macOS SDK, `codesign` για την υπογραφή της εφαρμογής). Όλα περιλαμβάνονται στα **Xcode Command Line Tools** (βλ. Βήμα 1 παρακάτω).
- **Frameworks:** Η εφαρμογή χρησιμοποιεί τα εγγενή frameworks της Apple (`AppKit`, `Foundation`, `Carbon`, `Contacts`, `UserNotifications`), τα οποία ενσωματώνονται αυτόματα από το macOS SDK.
- **Χώρος στον δίσκο:** Περίπου 2 GB ελεύθερος χώρος για τα Command Line Tools.
- **Σύνδεση στο διαδίκτυο:** Απαιτείται μόνο για τη λήψη των εργαλείων και του πηγαίου κώδικα.

> 💡 **Δεν χρειάζεστε** το πλήρες Xcode (10+ GB), το Homebrew ή λογαριασμό Apple Developer. Το project δεν έχει εξωτερικές εξαρτήσεις.

## 🚀 Διαδικασία Build

Ακολουθήστε τα παρακάτω απλά βήματα:

### Βήμα 1: Εγκατάσταση των Εργαλείων Ανάπτυξης (μία φορά)

Αν δεν έχετε ήδη εγκαταστήσει τα Xcode Command Line Tools, ανοίξτε το **Τερματικό** (Terminal) και τρέξτε:

```bash
xcode-select --install
```

Θα εμφανιστεί ένα παράθυρο του συστήματος. Πατήστε **«Εγκατάσταση»**, αποδεχτείτε τους όρους και περιμένετε να ολοκληρωθεί η λήψη (συνήθως 5-15 λεπτά, ανάλογα με τη σύνδεσή σας).

**Έλεγχος ότι η εγκατάσταση πέτυχε:**

```bash
swiftc --version
xcrun --sdk macosx --show-sdk-path
```

Αν και οι δύο εντολές εμφανίσουν αποτέλεσμα (έκδοση της Swift και μια διαδρομή προς το SDK) χωρίς σφάλμα, είστε έτοιμοι. Αν εμφανιστεί το μήνυμα `command line tools are already installed`, τότε τα εργαλεία υπάρχουν ήδη και μπορείτε να προχωρήσετε στο επόμενο βήμα.

> ⚠️ **Σημείωση:** Αν το παράθυρο εγκατάστασης δεν εμφανίζεται ή η λήψη αποτύχει, μπορείτε να κατεβάσετε τα Command Line Tools χειροκίνητα από το [developer.apple.com/download/all](https://developer.apple.com/download/all/) (απαιτείται δωρεάν Apple ID).

### Βήμα 2: Λήψη του Πηγαίου Κώδικα

Κατεβάστε τον φάκελο του project από το GitHub (πράσινο κουμπί **Code → Download ZIP**) και αποσυμπιέστε τον. Βεβαιωθείτε ότι ο φάκελος με το όνομα `HelloMac` βρίσκεται στον φάκελο των Λήψεών σας (`Downloads`).

### Βήμα 3: Άνοιγμα Τερματικού στον φάκελο του project

Ανοίξτε το Τερματικό και πλοηγηθείτε στον φάκελο όπου βρίσκεται το αρχείο build:

```bash
cd ~/Downloads/HelloMac
```

### Βήμα 4: Παροχή Δικαιωμάτων Εκτέλεσης

Πριν τρέξετε το script, πρέπει να του δώσετε τα απαραίτητα δικαιώματα εκτέλεσης:

```bash
chmod +x build_hellomac.sh
```

### Βήμα 5: Εκτέλεση του Script

Ξεκινήστε τη διαδικασία του build:

```bash
./build_hellomac.sh
```

### Βήμα 6: Ολοκλήρωση

Η διαδικασία θα τρέξει αυτόματα, θα κάνει compile τον κώδικα, θα προσθέσει τα εικονίδια και θα υπογράψει την εφαρμογή (ad-hoc code signing). Μόλις ολοκληρωθεί, η έτοιμη, μεταγλωττισμένη εφαρμογή **HelloMac** (το `.app` αρχείο) θα εμφανιστεί απευθείας στον φάκελο των Λήψεών σας, έτοιμη για χρήση!

## ▶️ Πρώτη Εκκίνηση της Εφαρμογής

Επειδή η εφαρμογή υπογράφεται τοπικά (ad-hoc) και όχι με πιστοποιητικό Apple Developer, το macOS ενδέχεται να εμφανίσει προειδοποίηση κατά το πρώτο άνοιγμα. Αυτό είναι φυσιολογικό.

1.  Κάντε **δεξί κλικ** πάνω στο `HelloMac.app` → **Άνοιγμα** → και πάλι **Άνοιγμα** στο παράθυρο που θα εμφανιστεί.
2.  Αν το macOS συνεχίζει να μπλοκάρει την εφαρμογή, μεταβείτε στις **Ρυθμίσεις Συστήματος → Απόρρητο & Ασφάλεια** και πατήστε **«Άνοιγμα ούτως ή άλλως»** στο κάτω μέρος της σελίδας.
3.  Όταν σας ζητηθεί, δώστε **άδεια πρόσβασης στις Επαφές**, ώστε να λειτουργήσει ο συγχρονισμός με το iCloud/iPhone.

## 🩺 Αντιμετώπιση Προβλημάτων

| Σφάλμα | Αιτία | Λύση |
| --- | --- | --- |
| `swiftc: command not found` | Δεν έχουν εγκατασταθεί τα Command Line Tools | Τρέξτε `xcode-select --install` |
| `xcrun: error: invalid active developer path` | Τα εργαλεία χρειάζονται επανεγκατάσταση (συνήθως μετά από αναβάθμιση του macOS) | Τρέξτε `xcode-select --install` ή `sudo xcode-select --reset` |
| `Permission denied: ./build_hellomac.sh` | Το script δεν έχει δικαιώματα εκτέλεσης | Τρέξτε `chmod +x build_hellomac.sh` |
| `No such file or directory` για αρχεία `.swift` | Ο φάκελος δεν έχει τη σωστή δομή ή το script δεν τρέχει από τη σωστή θέση | Βεβαιωθείτε ότι το script βρίσκεται δίπλα στον φάκελο `HelloMac/Sources/HelloMac/` |
| `⚠️ Εικονίδιο δεν βρέθηκε` | Λείπουν τα `phone.icns` / `menubar_icon.png` | Δεν είναι κρίσιμο: η εφαρμογή χτίζεται κανονικά, απλώς χωρίς εικονίδια. Τοποθετήστε τα αρχεία δίπλα στο script για να ενσωματωθούν |
| Η εφαρμογή «δεν μπορεί να ανοιχτεί επειδή προέρχεται από μη επαληθευμένο προγραμματιστή» | ad-hoc υπογραφή | Δείτε την ενότητα «Πρώτη Εκκίνηση» παραπάνω |
